budget 2024-01-03 
Fixed issue where the account totaller wasn't representing the full total.

This happened because the totaller assumed categories were unique. With the introduction of years,
a single category name may be present multiple times (e.g. 2023 -> Maint., 2024 -> Maint.).

The structure used to keep totals was a map of [category] -> total, so only the last written category
for whatever year was being captured.

The straightforward solution was to change the structure to [year] -> { [category] -> total }.

IOMAXIS

I led a small team (3-5 engineers) building a new cross-domain solution. I worked on all parts of the project (design, networking, implementation, build/deploy pipelines), but was also responsible for mentorship, team-building, and overall technical project direction.
Prior to that, I spent two years building a DoD-funded private cloud. Most of my time was spent increasing the performance and reliability of a custom protocol over UDP, but I also created web APIs, worked with tun/tap devices, and wrote a lot of async code (Rust, Python, Linux).

Goddard Space Flight Center
I spent two years at NASA Goddard, including two internships (Linux, Java, Python, Jenkins, Docker).
I built CI/CD pipelines, Dockerized applications, wrote ground system software for the James Webb Space Telescope, and created a compiler to translate ~50k lines of Fortran 77 to Java.

Custom Data Processing
